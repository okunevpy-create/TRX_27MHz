# Формат вызова инструментов — КРИТИЧНО

Все вызовы инструментов ДОЛЖНЫ оформляться строго блочным форматом `TOOL_NAME`.
Никаких JSON-объектов, XML-тегов (`<invoke>`, `<parameter>` и т.п.) или служебных тегов.

Структура вызова (каждый аргумент — отдельно):

- первая строка: `  - строка `BEGIN_ARG: имя_аргумента`
  - значение аргумента (может быть многострочным)
  - строка `END_ARG`

Требования:
1. Каждый вызов — отдельный блок, ограниченный тройными обратными кавычками с меткой `tool`.
2. Аргументы всегда непустые; значение размещать строго между `BEGIN_ARG` и `END_ARG`.
3. Блок вызова — последнее, что есть в сообщении. После закрывающего ограждения НИЧЕГО не писать.
4. Одновременно вызывать только один инструмент и дожидаться результата (если явно не разрешено иное).
5. Перед вызовом проверять, что имя аргумента точно соответствует схеме инструмента и не пустое.
6. При создании файла, содержимое которого включает тройные обратные кавычки, внешнее ограждение делать из БОЛЬШЕГО числа кавычек (например ````) либо описывать формат прозой без вложенных блоков.
