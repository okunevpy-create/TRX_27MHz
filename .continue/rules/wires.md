При проектировании схемы в KiCad, если провод (wire) получается слишком длинным либо его не удаётся развести без наложений/пересечений, не тянуть длинный провод — соединять цепи по имени с помощью локальных меток (local labels), а для межлистовых/межблочных соединений — глобальных меток (global labels). Одинаковое имя метки = одна цепь. Предпочитать этот подход длинной запутанной разводке.
