# План размещения компонентов — 01_control (этап 1)

Дата: **2026-10-31**. Плата **120 (X) × 90 (Y) мм**, 2 слоя. Вид — **со стороны F.Cu**,
origin — **левый верхний угол** Edge.Cuts (X → вправо, Y → вниз).

## Кромки разъёмов (зафиксировано)

| Кромка | Назначение | Разъёмы |
|---|---|---|
| **ЛЕВО** (X=0) | питание | `J_12V_IN_1` |
| **ПРАВО** (X=120) | ВЧ выходы | `J_VFO_1`, `J_BFO_1` |
| **ВЕРХ** (Y=0) | межплатные (02/03) | `J_PA_CTRL_1`, `J_I_SENSE_1`, `J_SWR_1`, `J_MODE_1`, `J_PTT_MUTE_1`, `J_AUDIO_1` |
| **НИЗ** (Y=90) | UI + отладка | `J_OLED_1`, `J_ENC_1`, `J_BTN_1`, `J_HS_1`, `J_LED_1`, `J_SWD_1`, `J_UART_1` |

> «Верх/низ» — физические кромки платы при взгляде со стороны F.Cu, **НЕ** слои F.Cu/B.Cu.

## Net-классы цепей (Board Setup → Design Rules → Net Classes)

Настраивается **после** `Tools → Update PCB from Schematic` (чтобы net-ы уже существовали).
Net-класс даёт маршрутизатору/Freerouting **дефолтную ширину** дорожки (в отличие от
custom DRC-правил, которые только ловят нарушения постфактум).

### Классы для создания  ✅ ВЫПОЛНЕНО

| Net class | Ширина | Зазор | Назначение |
|---|---|---|---|
| `PWR_12V` | **0.4** | 0.2 | вход 12 В, наибольший ток |
| `PWR_5V` | **0.3** | 0.2 | главная шина +5V (выход LM2596) |
| `PWR_3V3` | **0.3** | 0.2 | главная шина +3V3 (MCU+цифра) |
| *Default* | 0.2 | 0.2 | всё остальное |

### Назначение цепей (Net Class Assignment, точные имена)  ✅ ВЫПОЛНЕНО

| Шаблон | Net class |
|---|---|
| `VIN_PROT` | `PWR_12V` |
| `+5V` | `PWR_5V` |
| `+3V3` | `PWR_3V3` |

> ⚠️ Использовать **точные** имена, НЕ wildcard `+5V*`/`+3V3*`: иначе под шаблон
> попадут низкотоковые фильтрованные ветки `+5V_SI`, `+3V3_SI`, `+3V3_SI_F`,
> `+3V3_DISP`, `VDDA` — они должны остаться на Default 0.2.

### Земля — отдельно (не net-класс)  ✅ ВЫПОЛНЕНО

- В схеме сейчас **одна** цепь `GND` (188 пинов). Отдельных `GND_DIG`/`GND_ANA`/`GND_PWR` **в схеме нет**.
- Разделение земли «звезда в одной точке» делается **геометрией полигона** (единый net `GND`, форма заливки разведена к точке стыка), а не net-классами.
- Зазор полигона GND **0.3** задаётся: (а) на самом полигоне Clearance=0.3 + (б) DRC-правилом `HomeFab_gnd_clearance`.

### Via  ✅ ВЫПОЛНЕНО

- Один глобальный размер **Ø1.5 / drill 0.5** (Board Setup → Pre-defined Sizes). Per-class via не нужен.

## Зональная схема

```
         ВЕРХ (Y=0): J_PA_CTRL_1 J_I_SENSE_1 J_SWR_1 | J_MODE_1 J_PTT_MUTE_1 J_AUDIO_1
      ┌────────────────────────────────────────────────────────────┐
      │                                                             │
ЛЕВО  │  [1. ПИТАНИЕ]           [3. MCU]          [2. СИНТЕЗАТОР]    │  ПРАВО
X=0   │  J_12V_IN_1              U4 (QFN-48)        Si5351 + U8       │  X=120
      │  LM2596 → LDO            + кварц/decoup     → VFO/BFO         │
      │  (+3V3/+5V)              + EEPROM           J_VFO_1 J_BFO_1   │
      │                                                             │
      │  [4. UI + ОТЛАДКА] — OLED/ENC/BTN/HS/LED/SWD/UART            │
      └────────────────────────────────────────────────────────────┘
         НИЗ (Y=90): J_OLED_1 J_ENC_1 J_BTN_1 J_HS_1 J_LED_1 J_SWD_1 J_UART_1
```

## Порядок размещения (блоками, без скачков)

Порядок: **1 Питание → 2 Синтезатор → 3 MCU → 4 UI/отладка → 5 Интерфейсы → 6 LED**.
Каждый блок размещаем целиком, затем переходим к следующему.

### Шаг 1 — Питание (левый регион, X≈0..35)  ✅ ВЫПОЛНЕНО
Поток: вход слева → DC-DC → LDO (вправо/вглубь).

| Зона | Компоненты |
|---|---|
| Вход | `J_12V_IN_1` (левый край), `C1` 1000мкФ/25В, `C2` 100нФ |
| DC-DC | `U1` LM2596S-5 (TO-263), `L1` 33мкГн, `D3` SS34, `C3` 470мкФ/16В, `C4` 10мкФ |
| LDO +3V3 | `U2` RT9193, `L3` (феррит →U2_IN), `C5` 1мкФ, `C6` 10мкФ (bulk), `C45` 100нФ (ВЧ-выход), `C23` 10нФ (BP) |
| LDO +3V3_SI | `U3` RT9193, `L2` (феррит →+5V_SI), `C8` 100нФ, `C43` 1мкФ, `C7` 10мкФ, `C24` 10нФ |
| Фильтр Si5351 | `R5` 10Ω, `C21` 1мкФ |

> Силовой контур DC-DC (U1–L1–D3) — максимально компактно, это самый «грязный» узел.

### Шаг 2 — Синтезатор (правый регион, X≈85..120) ✅ ВЫПОЛНЕНО
Поток: Si5351/TCXO → буфер U8 → серия 22Ω → разъёмы VFO/BFO (правый край).

| Зона | Компоненты |
|---|---|
| Генератор | `U5` Si5351 (MSOP-10), `Y2` TCXO 27.6МГц, `C18`/`C19` 100нФ, `C42` 100нФ, `R3`/`R4` 4.7к (I2C pull-up) |
| Буфер | `U8` 74AC541 (SOIC-20), развязка `C15` 100нФ (VCC 20) |
| Выход | `R19`/`R20` 22Ω → `J_VFO_1`, `J_BFO_1` (правый край) |

> ВЧ тракт VFO/BFO — короткие дорожки, подальше от DC-DC и кнопок. GND-виа у разъёмов.

### Шаг 3 — MCU (центр, X≈40..80, Y≈20..70) ✅ ВЫПОЛНЕНО

| Зона | Компоненты |
|---|---|
| Ядро | `U4` STM32F411CEU6 (QFN-48, центр) |
| Такт | — внешний кварц Y1/C9/C10 **удалён**, MCU на внутреннем HSI 16 МГц |
| Развязка | U4: `C11`–`C14` (100нФ ×4) — по периметру U4, на каждую VDD (пины 1/24/36/48) |
| VDDA | `L4` феррит, `C20` 100нФ, `C25` 1мкФ |
| VCAP | `C22` 4.7мкФ (пин 22) |
| Конфиг | `R1` 10к (BOOT0), `R2` 10к (NRST) |
| EEPROM | `U10` AT24C02 (SO-8), развязка `C16` 100нФ — вплотную к `U10.8` (VCC) и `U10.4` (VSS/GND). I²C: SCL=U10.6, SDA=U10.5 |

> QFN-48: развязочные конденсаторы — максимально близко к пинам, со стороны корпуса.
>
> Бюджет +3V3 100нФ (8 шт): U4×4 = C11–C14 (VDD 1/24/36/48), U8×1 = C15 (VCC 20), U7×1 = C38 (V+ 8), U10×1 = C16 (VCC 8), C45 — запасной (на выход U2.5).
>
> Перестановка GPIO (U4): PB12(25)=ENC_CLK, PB13(26)=ENC_DT, PB14(27)=ENC_SW, PB15(28)=BTN_RIT; PC13(2)=BTN_LEFT, PC15(4)=BTN_UP.

## Проверка после размещения

- Все 16 разъёмов — на своих кромках (лево/право/верх/низ).
- Блоки не смешаны: питание слева, синтезатор справа, MCU в центре.
- Аналоговые цепи (RX_audio, I_sense, SWR_sense, MIC) не пересекают DC-DC узел.
- QFN-48 и MSOP-10: развязка вплотную.

## Разводка: что вести по F.Cu / B.Cu + размещение R/C элементов управления (сессия 2026-11-02)

### Размещение подтяжек и фильтрующих конденсаторов элементов управления

**Правило: RC-фильтр (подтяжка R + конденсатор C) — у приёмника, т.е. у пина MCU (U4), а не у разъёма.**

| Компоненты | Куда |
|---|---|
| `R12`–`R14` (10к) + `C35`–`C37` (100нФ) — энкодер | к `U4` (пины ENC_CLK/DT/SW), у входа GPIO |
| `R6`–`R11` (10к) + `C29`–`C34` (100нФ) — кнопки/джойстик | к `U4` (BTN_*), у входа GPIO |
| `R15`–`R18` (22Ω, SPI OLED) — согласующие | к `U4` (источник), **не** к `J_OLED_1` |

Причины:
1. Фильтр стоит на самом чувствительном узле — входе GPIO; после фильтра остаётся минимальный кусок проводника («антенны»), а навод не попадает в MCU нефильтрованным.
2. У MCU уже есть локальные `+3V3` (развязка C11–C14) и `GND` — подтяжку и конденсатор не нужно тянуть длинными ветками к разъёму. От MCU к разъёму идёт **одна** сигнальная дорожка, а не три (+сигнал/+3V3/GND) → меньше пересечений, легче развести в один слой.

> I²C подтяжки `R3`/`R4` (Si5351) и EEPROM-ветка — отдельный случай (у мастера/середины шины), это не «элементы управления».

### Что вести по слою B.Cu

**Можно и сигнал, и питание — ограничивают не тип цепи, а (1) минимум смен слоёв и (2) целостность GND-заливки.**

| Слой | Что ведём |
|---|---|
| **F.Cu** (основной, ~90%) | короткие сигнальные дорожки, вся развязка, **силовой контур DC-DC U1–L1–D3 (компактно, без переходов)** |
| **B.Cu** | короткие «перемычки через препятствие» (не влезло на F.Cu) + при необходимости длинные магистрали `+5V`/`+3V3`/`VIN_PROT` с короткими подъёмами к нагрузке |

Порядок принятия решений:
1. Развести всё на F.Cu.
2. Что не влезло без пересечений — коротким сегментом через B.Cu (сигнал или питание), сразу вернуться на F.Cu.
3. Длинные силовые магистрали — можно целиком на B.Cu, если это освобождает F.Cu под сигнал.
4. Считать число проволочных перемычек (via Ø1.5/drill 0.5); лишние убирать перепланировкой F.Cu.

Жёсткие ограничения:
- **Каждый переход F.Cu↔B.Cu = проволочная перемычка = лишняя пайка** → переходов минимум.
- **GND-заливка на B.Cu должна оставаться максимально цельной** (обратный путь тока): длинные параллельные сигнальные дорожки по B.Cu режут землю — избегать.
- **Аналог (RX_audio=PA0, I_sense=PA1, SWR_sense=PA2, MIC) — только F.Cu**, коротко и в стороне от DC-DC; через B.Cu без необходимости не гнать.
