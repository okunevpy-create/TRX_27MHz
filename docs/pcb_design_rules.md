## VIA (переходные отверстия)

- Технология — **проволочные перемычки**: отверстие 0.5 мм, тонкая проволока насквозь,
  пайка с обеих сторон на площадку 1.5 мм.
- Количество отверстий — **минимально необходимое** (каждое лишнее отверстие — лишняя пайка).

> ⚠️ **Исключение (этап 2, `02_power_amp`):** переходные отверстия — **заклёпочные
> пистоны**: сверло **0.9 мм**, площадка **2.5 мм** (аннулюс 0.8 мм). Действует только
> для платы этапа 2 (см. `docs/pcb_layout_stage2.md` §5).

## Питание и земля

- **Земля — единый `GND`**: сплошная заливка с обеих сторон; разделение «цифра/аналог/силовое» — **геометрией полигона** (звезда в одной точке у bulk-конденсатора C3 / входа `J_12V_IN_1`), **не** отдельными net-ами.
- **Полигон GND**: сплошная заливка **с обеих сторон**, **без thermal relief** (прямое
  соединение падов с полигоном). Зазор полигона **0.3 мм**.
- **Ширины силовых цепей** — по протекающему току (IPC-2221). Результат (см.
  `docs/calculations/power_trace_widths.md`): все токи ≤ 0.5 А → **0.2 мм достаточно**;
  для запаса: `+5V` = 0.3 мм, `VIN_PROT` = 0.4 мм.
- **Net-классы** (Board Setup → Net Classes): `PWR_12V` 0.4 (`VIN_PROT`), `PWR_5V` 0.3 (`+5V`),
  `PWR_3V3` 0.3 (`+3V3`), остальное Default 0.2. Назначение — **точными** именами (не wildcard).
- **ВЧ-разъёмы — SMA**: все ВЧ (VFO/BFO, TX_RF/RX_RF, ANT) = **SMA, партномер S-P215**.
  Символ — `Connector:Conn_Coaxial_Small` (центр + экран). Footprint — `trx_custom:SMA_S-P215`.

## DRC-правила (.kicad_dru) — синтаксис KiCad 10

⚠️ MCP-инструмент `drc_rule_create` пишет **невалидный** для KiCad 10 формат: оборачивает в
`(rules ...)` без `(version 1)` и с нижним регистром `A.Type`. Правильный формат (исправлен
вручную, проверен компиляцией в KiCad 10):

- Файл начинается с `(version 1)`.
- Нет обёртки `(rules ...)` — плоский список `(rule <Имя> ...)`.
- **`A.Type` регистрозависим**: `'Track'`, `'Via'`, `'Pad'`, `'Zone'`, `'Text'`, `'Edge_Cuts'`.
  Строчные `'via'` / `'none'` — ошибка компиляции.
- Несколько ограничений в одном правиле допустимо, напр.:
  `(rule HomeFab_via_geometry (condition "A.Type == 'Via'") (constraint via_diameter (min 1.5mm)) (constraint annular_width (min 0.5mm)) (severity error))`.

Текущие правила `01_control.kicad_dru`: edge 0.5 / via Ø1.5+annulus 0.5 / hole-to-hole 0.5 /
GND зазор 0.3 / VIN 0.4 / +5V 0.3.

## Компоновка

- Габариты плат определяются **перед началом разводки**.
- `01_control` — рабочий лимит **120 × 90 мм** (Ш×Г; финал — по факту разводки).
- **Кромки разъёмов** (вид со стороны F.Cu): **слева** — питание (`J_12V_IN_1`); **справа** —
  ВЧ выходы (`J_VFO_1`, `J_BFO_1`); **сверху/снизу** — коммутационные (сверху межплатные к 02/03,
  снизу UI/отладка). «Верх/низ» — физические кромки платы, не слои F.Cu/B.Cu.
  См. `pcb_layout_stage1.md`.
- 4 монтажных отверстия M3 Ø3.2 по углам — см. `pcb_placement_plan.md` §6.
- Идентификация компонентов — **без шелкографии**: при распайке сверка платы с разводкой
  на экране + BOM + схема.

## Разделение работ

- **Размещение + поворот + трассировка** — пользователь, в GUI KiCad (трассировка через плагин Freerouting).
- **Агент** — готовит правила/доки/план и **проверяет результат** (`run_drc`, gates, bbox).
  У агента НЕТ `pcb_place/move/rotate` и `route_autoroute_freerouting` (подтверждено 2026-10-31).
