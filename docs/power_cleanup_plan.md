# План чистки питания — `01_control` (сессия «переразводка питания»)

## Цель
Привести секцию питания платы управления (`KiCad/01_control/01_control.kicad_sch`)
в соответствие с BOM и финальными решениями пользователя, устранить
короткозамкнутые развязочные конденсаторы, добавить недостающие элементы
(VDDA, F10, L3, R_si) и выровнять refdes/значения. **Только schematic — PCB не трогать.**
Плату этапа 1 не травить/монтировать (запрет до 1.5+2.3 и фиксации `control_pa.md`).

## Финальные решения (согласованы с пользователем — НЕ переспрашивать)
1. **VCAP2 отсутствует.** `MCU_ST_STM32F4:STM32F411CEUx` имеет единственный VCAP
   (pin 22 = VCAP1, `power_out`). → **C17b удалить из BOM**, VCAP1 = **C22 (2.2 мкФ)**.
2. **F10 (R_si) топология:** `U3 OUT → C7(10мкФ) → GND`, затем
   `+3V3_SI → R_si(10Ω) → +3V3_SI_F`, локально `C21(1мкФ)+C18(100нФ)+C19(100нФ) → GND`.
   Выходной конденсатор U3 (C7) стоит **до** R_si.
3. **Тантал C6 убирается.** RT9193 требует керамику 1–10 мкФ на выходе; тантала нет
   на складе; правило 0603. C6 = **10 мкФ 10В X7R** (керамика).
4. **Ферриты L2 и L3:** BLM21SP181SN1D → **MMZ2012R601AT000** (0805, 600Ω@100МГц).

## Наличие номиналов (сверено по складу)

## Целевая топология питания
```
+12V_IN → F1 → VIN_F → D1(TVS→GND) + D2(анод)
D2(катод) → VIN_PROT → C1(+)+C2(+) → GND; U1 VIN
U1 OUT → SW_OUT → L1 → +5V; D3(SW_OUT→GND)
+5V → C3+C4 → GND
+5V → L3(MMZ2012R601) → U2 IN; C5(1мкФ) на входе U2
U2 OUT → +3V3 → C6(10мкФ) → GND
+5V → L2(MMZ2012R601) → +5V_SI → U3 IN; C8(100нФ) на входе U3
U3 OUT → +3V3_SI → C7(10мкФ) → GND
+3V3_SI → R_si(10Ω, refdes R5) → +3V3_SI_F
   └─ C21(1мкФ)+C18(100нФ)+C19(100нФ) → GND; R3/R4 → I2C; U5:1, U5:7
+3V3: C11–C16(100нФ), C20(VDDA 100нФ)+C25(VDDA 1мкФ), U4 VDD/VDDA
VCAP1 = C22 (2.2мкФ) → U4:22
BP U2 = C23 (10нФ), BP U3 = C24 (10нФ)
```

## Изменения refdes
- `C20` (10нФ BP U2) → **C23**; `C21` (10нФ BP U3) → **C24**.
- Освободившиеся `C20` = VDDA 100нФ, `C21` = F10 1мкФ.
- Добавить: `C25` = VDDA 1мкФ, `R5` = R_si 10Ω, `L3` = феррит.
- Удалить: старый `C17` (1мкФ, КЗ). VCAP1 = `C22` (C17b удалить из BOM).

## Текущие КЗ (ERC не видит; подтверждено connectivity graph)
- **C2** — оба пина GND → pin1 должен быть `VIN_PROT`.
- **C11/C12/C13** — оба пина `+3V3` → pin2 должен быть GND.
- **C15/C16** — оба пина GND → pin1 должен быть `+3V3`.
- C14 корректен (+3V3/GND).

## Подводные камни
- **ERC не ловит короткие пассивы** — проверять по `sch_get_connectivity_graph` + `sch_get_wires`.
- **U2/U3 не резолвятся в connectivity graph / pin positions** (MCP не резолвит координаты
  пинов `trx_custom`). Выводить пины по `lib_get_symbol_info` (1 IN, 2 GND, 3 EN, 4 BP, 5 OUT)
