## Принятые решения (кратко)
- 4 этапа + этап 0 (мастер-лист); подэтапы внутри.
- Питание: общая защита, локальная стабилизация. **Топология — звезда**: входной узел защиты физически на `01_control`, отдельные линии на PA и rxtx (PA даёт импульсные броски — общая шина недопустима).
- Имена питания межблочные: `+12V_PA` (control→PA), `+12V_RXTX` (control→rxtx) — разные цепи.
- Ограничитель AM: физический тумблер LIMIT/FULL на УМ, обратная связь PWR_LIMIT_SW.
- RIT: программный, энкодер 10/100 Гц, кнопка, OLED, EEPROM.
- Squelch: программный на `01_control`, сигнал RX_audio с `03_rx_tx`.
- T/R: реле на `02_power_amp`, защита RX диодами + аттенюатор на `03_rx_tx`.
- ВЧ-связь PA↔rxtx — **напрямую, минуя control**: `TX_RF` (rxtx→PA), `RX_RF` (PA→rxtx). Отдельный контракт `rxtx_pa.md`.
- Земля: на Этапе 0 один `GND`; на реальных платах раздельная (GND_DIG/GND_ANA/GND_PWR), соединение в одной точке.
- Гарнитура — Baofeng/Kenwood 2-pin (K1). Разъёмы на корпусе, на платах — пады под проводной монтаж. MIC/PTT → `01_control`, SP+/GND → `03_rx_tx`. `MIC_LINE` и `MUTE` — в контракте `control_rxtx.md`.
- FM: опционально, место заложено, монтаж после AM/SSB.
- BOM: обязателен до разводки, срок доставки 3–4 дня.

## Правила работы (зафиксированы в Rules)
- Не редактировать один файл параллельно — по одной операции, перечитывать перед следующей.
- Не запускать параллельно несколько KiCad MCP запросов — по одному, ждать результат.

### Решения сессии (Этап 1 — анализ)
- MCU: корпус **UFQFPN-48 7x7** (STM32F411CEUx + QFN-48-1EP_7x7mm_P0.5mm_EP5.6x5.6mm).
- TVS: обобщённый `Device:D_TVS` (подстроить под заказ).
- Диод входа: SS34 (SMA, D_SMA_Handsoldering).
- Пассивные: **0603** (правило в Rules), номиналы из resistance_0603.csv / capacitors_0603.csv.
- Footprint: правило handsoldering (Rules).
- BOM `stage1_control.md` разбит по подэтапам 1.1–1.5 с символами и footprint.
- Схема `01_control` пустая — старт с 1.1.

### Прогресс Этапа 1
- **1.1 — СХЕМОТЕХНИКА ГОТОВА** (17 компонентов: входная защита F1/D1/D2, DC-DC LM2596 U1+L1+D3, LDO 3.3В U2+C5/C6, отдельный LDO +3V3_SI U3+L2+C7/C8, пассив C1/C2/C3/C4). Все цепи соединены метками (правило: длинные провода → метки). ERC: реальных ошибок 1.1 нет.
- 15 каркасных интерфейсных меток (PTT…MUTE) оставлены в корне до 1.5 → ERC «красный» по ним (согласовано).
- Footprint'ы: L1=L_12x12mm_H4.5mm, C6=Tantalum CP_EIA-3216-18_Kemet-A_HandSolder (исправлены).

- **1.2 — СХЕМОТЕХНИКА ГОТОВА** (U4 STM32F411CEU6 QFN-48, Y1 8МГц+C9/C10 20пФ, развязка C11–C17 100нФ/1мкФ, R2 NRST pull-up 10к, R1 BOOT0 pull-down 10к, J_SWD, J_UART 1x04). Цепи: +3V3/GND, OSC_IN/OUT, NRST, BOOT0, SWDIO/SWCLK, UART_TX/RX. Лист увеличен A4→A3.
- ERC 1.2: реальных ошибок по задействованным пинам нет; «Pin not connected» у неиспользуемых GPIO — ожидаемо (часть задействуется в 1.3/1.4). Открыт вопрос: NC-крестики на неиспользуемые GPIO или изменить severity — решается пользователем.

### Уточнения компонентов (по решению пользователя)
- TVS D1: **SMBJ18A** (SMB, uni 18В), footprint D_SMB_Handsoldering; value обновлён.
- Кварц MCU Y1: **8 МГц HC-49SM, P/N SJK-6C-8.000-16-30-50-C-50-H** (SMD), footprint Crystal_SMD_HC49-SD_HandSoldering; value в схеме = P/N.
- Энкодер: **модуль KY-040, монтаж на корпус**, на плате — разъём 5-pin (J_ENC), не сам энкодер.
- Дисплей: **OLED 0.96" 128×64 I2C (синий, модуль SSD1306)**, на плате — разъём 4-pin (J_OLED: VCC/GND/SCL/SDA).
- **ОБЩЕЕ ПРАВИЛО: ВСЕ элементы управления (энкодер KY-040, кнопки, OLED) монтируются НА КОРПУС, подключаются проводами. На платах — только разъёмы/пады под провода.** Кнопки → J_BTN (4-pin).
- Кварц Si5351 Y2 (этап 1.3): **TG2520SMN-27.6000M-MCGNNM3** (27.6 МГц, SMD 2520).
- BOM (stage1_control.md) и схема D1/Y1 обновлены; Y2 — при разводке 1.3.

- **1.3 — СХЕМОТЕХНИКА ГОТОВА**: U5 Si5351A-B-GT (MSOP-10), Y2 TG2520SMN-27.6МГц (2520), C18/C19 развязка, R3/R4 I2C pull-up 4.7к; U6 74HC74 (3 юнита) — делитель IQ (CLK←IQ_CLK, D1=/Q2, D2=Q1, CLR/PRE→+3V3). Выходы: CLK0→VFO_RAW, CLK1→BFO_RAW, CLK2→IQ_CLK; I(Q1), Q(Q2). I2C: MCU PB6/PB7 → I2C_SCL/SDA. Буферы VFO/BFO/IQ и подключение VFO_RAW/BFO_RAW — в 1.5.
- ERC 1.3: ошибки по U5/U6/Y2/C18/C19 устранены. Остаются: неиспользуемые GPIO MCU (до 1.5) + изолированные VFO_RAW/BFO_RAW (до буферов 1.5).

Схемотехника подэтапов:
1. **1.1** — входной узел защиты + DC-DC 12→5 В + LDO 3.3 В + `+3V3_SI`.
2. **1.2** — MCU STM32F411 + кварц + SWD + UART.
3. **1.3** — Si5351 + 74HC74 + буферы VFO/BFO/IQ.
4. **1.4** — UI (OLED, энкодер), память каналов, RIT, squelch; пады MIC/PTT/предусилитель, `MIC_LINE`.
5. **1.5 + 2.3 совместно** — интерфейсы (PTT, I_sense, SWR_sense, PWR_LIMIT_*, RX_audio, MUTE) + лимитер/тумблер на PA.
