## Текущий этап
**Этап 0 — мастер-лист** (следующая сессия).

## Принятые решения (кратко)
- 4 этапа + этап 0 (мастер-лист); подэтапы внутри.
- Питание: общая защита, локальная стабилизация. **Топология — звезда**: входной узел защиты физически на `01_control`, отдельные линии на PA и rxtx (PA даёт импульсные броски — общая шина недопустима).
- Имена питания межблочные: `+12V_PA` (control→PA), `+12V_RXTX` (control→rxtx) — разные цепи.
- Ограничитель AM: физический тумблер LIMIT/FULL на УМ, обратная связь PWR_LIMIT_SW.
- RIT: программный, энкодер 10/100 Гц, кнопка, OLED, EEPROM.
- Squelch: программный на `01_control`, сигнал RX_audio с `03_rx_tx`.
- T/R: реле на `02_power_amp`, защита RX диодами + аттенюатор на `03_rx_tx`.
- ВЧ-связь PA↔rxtx — **напрямую, минуя control**: `TX_RF` (rxtx→PA), `RX_RF` (PA→rxtx). Отдельный контракт `rxtx_pa.md`.
- Земля: на Этапе 0 один `GND`; на реальных платах раздельная (GND_DIG/GND_ANA/GND_PWR), соединение в одной точке.
- FM: опционально, место заложено, монтаж после AM/SSB.
- BOM: обязателен до разводки, срок доставки 3–4 дня.

## Правила работы (зафиксированы в Rules)
- Не редактировать один файл параллельно — по одной операции, перечитывать перед следующей.
- Не запускать параллельно несколько KiCad MCP запросов — по одному, ждать результат.
