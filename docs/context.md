## Текущий этап
**Этап 1 (`01_control`)**: схемотехника 1.1–1.3 ГОТОВА, 1.4 (UI/MIC) — следующая сессия. Этап 0 (мастер-лист) — ОТЛОЖЕН (см. ниже).

> Этап 0 в KiCad — концептуальная блок-схема. Источник правды по интерфейсам — `docs/contracts/` и `docs/inter-module-pinout.md`, а НЕ ERC мастера.

## Принятые решения (кратко)
- 4 этапа + этап 0 (мастер-лист); подэтапы внутри.
- Питание: общая защита, локальная стабилизация. **Топология — звезда**: входной узел защиты физически на `01_control`, отдельные линии на PA и rxtx (PA даёт импульсные броски — общая шина недопустима).
- Имена питания межблочные: `+12V_PA` (control→PA), `+12V_RXTX` (control→rxtx) — разные цепи.
- Ограничитель AM: физический тумблер LIMIT/FULL на УМ, обратная связь PWR_LIMIT_SW.
- RIT: программный, энкодер 10/100 Гц, кнопка, OLED, EEPROM.
- Squelch: программный на `01_control`, сигнал RX_audio с `03_rx_tx`.
- T/R: реле на `02_power_amp`, защита RX диодами + аттенюатор на `03_rx_tx`.
- ВЧ-связь PA↔rxtx — **напрямую, минуя control**: `TX_RF` (rxtx→PA), `RX_RF` (PA→rxtx). Отдельный контракт `rxtx_pa.md`.
- Земля: на Этапе 0 один `GND`; на реальных платах раздельная (GND_DIG/GND_ANA/GND_PWR), соединение в одной точке.
- Гарнитура — Baofeng/Kenwood 2-pin (K1). Разъёмы на корпусе, на платах — пады под проводной монтаж. MIC/PTT → `01_control`, SP+/GND → `03_rx_tx`. `MIC_LINE` и `MUTE` — в контракте `control_rxtx.md`.
- FM: опционально, место заложено, монтаж после AM/SSB.
- BOM: обязателен до разводки, срок доставки 3–4 дня.
- **ЭЛЕМЕНТЫ УПРАВЛЕНИЯ (энкодер KY-040, кнопки, OLED) монтируются НА КОРПУС, подключаются проводами. На платах — только разъёмы/пады под провода.**

## Правила работы (зафиксированы в Rules)
- Не редактировать один файл параллельно — по одной операции, перечитывать перед следующей.
- Не запускать параллельно несколько KiCad MCP запросов — по одному, ждать результат.
- Если не удаётся отредактировать текстовый файл за 3 попытки — удалить и пересоздать целиком (create_new_file).

## Следующий шаг — Этап 1 (`01_control`), подэтап 1.4
BOM `stage1_control.md` актуален. Схемотехника 1.1–1.3 готова. Далее — **1.4 (UI / RIT / squelch / MIC-предусилитель)**.

### Решения (Этап 1 — анализ)
- MCU: корпус **UFQFPN-48 7x7** (STM32F411CEUx + QFN-48-1EP_7x7mm_P0.5mm_EP5.6x5.6mm).
- TVS: **SMBJ18A** (SMB, D_SMB_Handsoldering).
- Диод входа: SS34 (SMA, D_SMA_Handsoldering).
- Пассивные: **0603** (номиналы из resistance_0603.csv / capacitors_0603.csv).
- Footprint: правило handsoldering (при наличии), иначе обычный SMD/THT.
- BOM `stage1_control.md` разбит по подэтапам 1.1–1.5.

### Прогресс Этапа 1
- **1.1 — СХЕМОТЕХНИКА ГОТОВА** (17 компонентов: F1/D1/D2, DC-DC LM2596 U1+L1+D3, LDO 3.3В U2+C5/C6, LDO +3V3_SI U3+L2+C7/C8, пассив C1/C2/C3/C4). Цепи соединены метками. ERC: реальных ошибок 1.1 нет.
- 15 каркасных интерфейсных меток (PTT…MUTE) оставлены в корне до 1.5 → ERC «красный» по ним (согласовано).
- Footprint'ы: L1=L_12x12mm_H4.5mm, C6=Tantalum CP_EIA-3216-18_Kemet-A_HandSolder.
- **1.2 — СХЕМОТЕХНИКА ГОТОВА** (U4 STM32F411CEU6 QFN-48, Y1 8МГц+C9/C10 20пФ, развязка C11–C17, R2 NRST pull-up 10к, R1 BOOT0 pull-down 10к, J_SWD, J_UART 1x04). Цепи: +3V3/GND, OSC_IN/OUT, NRST, BOOT0, SWDIO/SWCLK, UART_TX/RX. Лист A4→A3.
- ERC 1.2: реальных ошибок по задействованным пинам нет; «Pin not connected» у неиспользуемых GPIO — ожидаемо.
- **1.3 — СХЕМОТЕХНИКА ГОТОВА**: U5 Si5351A-B-GT (MSOP-10), Y2 TG2520SMN-27.6МГц (2520), C18/C19 развязка, R3/R4 I2C pull-up 4.7к; U6 74HC74 (3 юнита) — делитель IQ (CLK←IQ_CLK, D1=/Q2, D2=Q1, CLR/PRE→+3V3). Выходы: CLK0→VFO_RAW, CLK1→BFO_RAW, CLK2→IQ_CLK; I(Q1), Q(Q2). I2C: MCU PB6/PB7 → I2C_SCL/SDA. Буферы VFO/BFO/IQ и подключение VFO_RAW/BFO_RAW — в 1.5.
- ERC 1.3: ошибки по U5/U6/Y2/C18/C19 устранены. Остаются: неиспользуемые GPIO MCU (до 1.5) + изолированные VFO_RAW/BFO_RAW (до буферов 1.5).

### Уточнения компонентов (по решению пользователя)
- TVS D1: **SMBJ18A** (SMB, uni 18В), footprint D_SMB_Handsoldering; value обновлён.
- Кварц MCU Y1: **8 МГц HC-49SM, P/N SJK-6C-8.000-16-30-50-C-50-H** (SMD), footprint Crystal_SMD_HC49-SD_HandSoldering; value = P/N.
