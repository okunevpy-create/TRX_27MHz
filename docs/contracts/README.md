# Интерфейсные контракты

Контракт фиксирует сигналы на межмодульном разъёме **до** разводки плат. Это **предварительное условие**, а не этап. Меняется только по явному согласованию.

## Правила
- Каждый контракт — отдельный файл.
- Таблица: сигнал, направление, уровень, тип, разъём/пин.
- При изменении — обновить контракт, затем обе платы.
- Если контракт не зафиксирован — разводку не начинать.
