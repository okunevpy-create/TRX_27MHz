## 3. Задачи (1.4)

### 3.1 — MIC-предусилитель U7 (LM358, unit A, **неинвертирующий**)

Цоколёвка LM358 (SOIC-8): 1=OUT A, 2=IN− A, 3=IN+ A, 4=GND(V−), 8=VCC(V+). Unit B (5/6/7) уже на GND/NC.

Однополярное питание **+3V3**, смещение 0.5×Vcc = **1.65 В**, усиление ≈ **11** (`1 + R_fb/R_g = 1 + 100к/10к`).

```
+3V3 ── R_bias 2.2к ── MIC+   (электрет; MIC− → GND)
MIC+ ── C_cpl 1мкФ ── V+   (U7 pin 3)
V+ ── R_in 10к ── +3V3
V+ ── R_g 10к  ── GND        → смещение 1.65 В
Vout(pin1) ── R_fb 100к ── V− (U7 pin 2)
V− ── R_gain 10к ── C_fb ── GND   → усиление ≈ 11 (DC gain = 1 за счёт C_fb)
Vout(pin1) ── MIC_LINE (иерархическая метка)
```

> **Почему R_gain и C_fb:** неинвертирующий усилитель требует путь от V− к земле (R_gain) для задания усиления. На однополярном питании C_fb в ОС нужен, чтобы по постоянному току усиление было = 1 (выход держится на 1.65 В), а по переменному — ≈ 11. Без C_fb выход уйдёт в насыщение (~1.8 В) и потеряет переменную составляющую.

### 3.2 — Вход `RX_audio` → ADC MCU (RC, squelch программный)

```
RX_audio ── R_rc 1к ──┬── к пину MCU (ADC)
                       └── C_rc 10нФ ── GND
```
τ = 1к × 10нФ = 10 мкс — антиалиасинг, не давит звук (squelch — в прошивке).

### 3.3 — RIT: только цепи (логика в прошивке)

Кнопка RIT уже в `J_BTN` (8-pin), энкодер в `J_ENC` (5-pin). Ничего нового не добавлять — проверить, что линии `BTN_RIT`/`ENC_*` заведены через RC-фильтры.
