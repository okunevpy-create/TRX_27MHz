## 3. Зональная схема (рекомендация)

```
            ЛЕВО (к плате 2):                  ПРАВО (к плате 1):
            J2  (TX_RF, SMA → 02 TX)           J3   (VFO, SMA → 01 VFO)
            J1  (RX_RF, SMA → 02 RX)           J4   (BFO, SMA → 01 BFO)
          ┌──────────────────────────────────────────────────────────────┐
          │                                                              │
          │  [1. RX-ВХОД 27 МГц]                                         │
          │   J1 → D1/D2 + T-pad (R1/R2/R3) → BPF RX (L1/L2+C1–C5)       │
          │   → K1 (реле, NC)                                            │
          │                                                              │
          │  [2. СМЕСИТЕЛЬ U1 + T/R]  U1 (NE612) + K1 (IM06GR) + Q2      │
          │                                                              │
          │  [3. КВАРЦЕВЫЙ ФИЛЬТР 10 МГц]  X1–X4 + C16–C21 + D3–D5        │
          │                                                              │
          │  [4. ДЕТЕКТОР/МОДУЛЯТОР + УНЧ + ДРАЙВЕР TX]                   │
          │   U2 → U3 (LM386) → J9;  U4 → Q1 → BPF TX → J2               │
          │                                                              │
          │  [5. ПИТАНИЕ]  U5 (LM7809) + U6 (L78L06) + C40–C45           │
          └──────────────────────────────────────────────────────────────┘
            НИЗ (питание + управление): J8  J5  J6  J7  J9
```

- **Тракт 27 МГц** (RX: `J1` → BPF RX → K1/U1; TX: U4 → Q1 → BPF TX → `J2`) —
  у левой кромки, по одной линии сигнала, компактно, вдали от аудио.
- **Кварцевый фильтр 10 МГц** — симметричный «лесенкой», X1–X4 в одну линию,
  связующие ёмкости/диоды по бокам; минимум паразитных петель.
- **Гетеродины VFO (37 МГц) / BFO (10 МГц)** — приходят справа (`J3`/`J4`), дорожки к своим
  NE612 вести раздельно (VFO → U1, BFO → U2/U4); не вести параллельно длинными участками.
- **Аудио (U2 → LM386 → J9; RX_audio/MIC_LINE)** — у нижней кромки, в стороне от ВЧ.
- **Питание (U5/U6)** — у нижнего входа `J8`, развязка у каждой ИС.

## 4. Ширина дорожек — единый Default (Board Setup → Net Classes)

**Решение (2026-11-05): всё разводим одним классом `Default` 0.6 мм.**

- Отдельные net-классы (`RF_RXTX`/`LO_RXTX`/`PWR_RXTX`) **не создаём**: все токи
  ≤ 0.25 А, единая ширина **0.6 мм** покрывает всё с запасом >10×
  (`power_budget_stage3.md` §4 — ΔU ≤ 8.4 мВ, ΔT ≤ 0.1 °C).
- `Board Setup → Net Classes`: **Default = 0.6 мм**, зазор **0.4 мм**. Больше ничего.
- Классы не давали бы выигрыша: они не меняли бы ширину (всё и так 0.6 мм), а явных
  DRC-правил по ширине нет (нет цепей с током > 0.25 А). Согласование 50 Ом не
  требуется — на 27 МГц все трассы ≪ λ/20 (λ ≈ 11 м).

## 7. Разводка: F.Cu / B.Cu

**Ограничивает не тип цепи, а (1) минимум смен слоёв и (2) целостность GND-заливки.**

| Слой | Что ведём |
|------|-----------|
| **F.Cu** (основной, ~95 %) | весь тракт 27 МГц (`RX_RF`→…→`TX_RF`), ПЧ 10 МГц (`IF_MIX`/`N1–N3`/`IF_BB`/`DSB`), гетеродины `VFO`/`BFO`, питание `+12V_RXTX`/`+9V`/`+6V`, аудио |
| **B.Cu** | только короткие «перемычки через препятствие» (не влезло на F.Cu); **GND-заливка** |

Жёсткие ограничения:
- **Каждый переход F.Cu↔B.Cu = заклёпочный пистон = лишняя ручная операция** → переходов минимум.
- **ВЧ/ПЧ/гетеродины — только F.Cu**, одной короткой линией, без перемычек по B.Cu; под ними — сплошной GND (B.Cu полигон).
- **Кварцевый фильтр** — X1–X4 по одной прямой, связующие ёмкости/диоды прижаты к узлам N1/N2/N3; дорожки N-узлов минимальной длины, симметрично.
- **Гетеродины VFO и BFO — разнести** (VFO у U1, BFO у U2/U4), дорожки короткие, не вести параллельно длинными участками (наводка 37↔10 МГц).
- **Аудио (LM386, `RX_audio`, `MIC_LINE`, `SP`) — в стороне от ВЧ/гетеродинов**, обратный путь аудио — своя зона GND.
- **GND-заливка на B.Cu — максимально цельная**; длинные параллельные сигнальные дорожки по B.Cu режут землю — избегать.
- **Flyback `D6`** — максимально близко к катушке реле `K1` (параллельно катушке 1–8).
