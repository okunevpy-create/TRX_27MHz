# Этап 2 — проектные решения для схемотехники 2.1–2.3

> Фиксируется перед построением схемы `02_power_amp`. Источник правды по составу — `docs/bom/stage2_power_amp.md`; по интерфейсам — `docs/contracts/`.

## 0. Исходные факты (сверено через MCP)
- Схема `02_power_amp` — пустая.
- Символы: `trx_custom:RD16HHF1` (1=GATE, 2=SOURCE, 3=DRAIN); `trx_custom:IM06GR` (8 пинов без имён).
- Символы KiCad: `Device:Transformer_1P_1S` (1=AA, 2=AB, 3=SA, 4=SB), `Device:Transformer_SP_1S` (1=PR1, 2=PM, 3=PR2, 4=S1, 5=S2), `Transistor_FET:2N7002` (1=G, 2=S, 3=D), `Amplifier_Operational:LM358` (1=OUT1, 2=IN1−, 3=IN1+, 4=V−, 5=IN2+, 6=IN2−, 7=OUT2, 8=V+), `Connector:Conn_Coaxial` (1=In, 2=Ext).

## 1. Распиновка реле K1 (IM06GR / 2-1462037-3) — выведено из геометрии символа
Символ `IM00` рисует катушку слева и два перекидных контакта справа. Подвижные (общие) контакты подключены к пинам **3** и **6**; катушка — к **1** (+) и **8** (−).

| Пин | Функция |
|-----|---------|
| 1 | Катушка + |
| 8 | Катушка − |
| 3 | COM1 (подвижный) |
| 2 | NC1 (разрывной) |
| 4 | NO1 (замыкающий) |
| 6 | COM2 (подвижный) |
| 7 | NC2 (разрывной) |
| 5 | NO2 (замыкающий) |

Используется полюс 1: COM1→`ANT`, NO1→`LPF_OUT`(TX), NC1→`RX_RF`. Полюс 2 (5/6/7) — не подключён (резерв).

**PTT-драйвер реле:** `PTT` (J_PA_CTRL_1:2) → Q4 (2N7002) затвор; сток → катушка K1:8, исток → GND. Затвор Q4 подтянут к GND через **R20 (10 кОм)** — при отключённом разъёме реле гарантированно выключено (RX).

## 2. Смещение затворов (2.3)
- Делитель: `+12V_PA → R5(10k) → VGG_FULL → R6(2.7k) → GND` → ≈2.55 В.
- RV1 (3296W 10k) между `VGG_FULL` и GND, движок = `VGG_LIMIT`.
- `VGG` подтянут к `VGG_FULL` через **R19 (100k)** (по умолчанию FULL).
- Подача на затворы: `VGG → R3/R4 (10k) → Q1/Q2.GATE`. R1/R2 (4.7 Ом) — антипаразитные последовательно с балуном.
- `C5` (100 нФ) — развязка узла VGG.
- **`J_SW_1` (3P):** 1=`PWR_LIMIT_SW`, 2=`PLIM_LIM`, 3=`GND` — только логика; `VGG`/`VGG_LIMIT`/`VGG_FULL` на панель не выходят.
- Значения «по расчёту», финально на плате по току покоя.

## 3. LIMIT/FULL + PWR_LIMIT (2.3)
- `PLIM_LIM`: `+12V_PA → R7(27k) → PLIM_LIM → R8(10k) → GND` = 3.24 В (LIMIT=HIGH, 3.3 В-совместимо для MCU).
- Тумблер SW1 (SPDT): COM=`PWR_LIMIT_SW` (J_SW_1:1); LIMIT=`PLIM_LIM` (J_SW_1:2); FULL=`GND` (J_SW_1:3).
- **Аппаратный LIMIT:** `PWR_LIMIT_SW` (HIGH в LIMIT) → Q5 (2N7002) gate; Q5 D→`VGG`, S→`VGG_LIMIT`.
- **Программный LIMIT:** `PWR_LIMIT_EN` (J_PA_CTRL_1:3) → Q3 (2N7002) gate; Q3 D→`VGG`, S→`VGG_LIMIT` (параллельно Q5, «ИЛИ» с тумблером).
- `VGG` по умолчанию FULL (через R19 100k), притягивается к `VGG_LIMIT` любым из ключей Q3/Q5.
- **Подтяжка безопасного дефолта (2026-11-04):** **R21 (100 кОм, 0603)** между `PWR_LIMIT_SW` и `PLIM_LIM` — при отключённом тумблере затвор Q5 подтянут к HIGH → ограничитель активен (LIMIT, 4 Вт), а не полная мощность. В положении FULL тумблер держит `PWR_LIMIT_SW` на GND (ток через R21 ~32 мкА), поэтому FULL не нарушается.

## 4. LED «LIMIT активен» = (тумблер LIMIT) ИЛИ (PWR_LIMIT_EN)
- Диодное ИЛИ: D2 (A←`PWR_LIMIT_SW`), D3 (A←`PWR_LIMIT_EN`), катоды → `LIMIT_ACTIVE`.
- `LIMIT_ACTIVE → R10 → D6 → GND` (платный дубль) и `LIMIT_ACTIVE → R9 → J_LIM_LED_1:1` (панель).
- D2/D3 = 1N4148WS ×2 — уже в BOM.

## 5. I_sense (2.3) — низкосторонний шунт
- R_shunt (0.05 Ом) в минусовой шине: `GND_PA → R_shunt → GND`.
- LM358 канал A неинвертирующий: IN1+ ← `GND_PA`; IN1− ← R_sen_in(1k)→GND и R_sen_fb(22k)→OUT1; G≈23 (≈3.3 В на 2.9 А). OUT1 → R_sen_out(1k) → `I_sense` → J_PA_CTRL_1:5; C_sen(100нФ) фильтр.
- Канал B неиспользуем: IN2+ → GND, IN2− → OUT2 (повторитель).

## 6. SWR_sense (2.3) — return-loss мост (отражённая мощность)
- T3 (BN-61-202, `Device:Transformer_1P_1S`): первичка AA/AB — **1 проход линии ANT в разрыв** (`ANT_RELAY`←`K1:3` → `ANT`→`J_ANT_1`); вторичка SA→GND, SB→`SWR_RF` (20–30 витков Ø0.3 мм).
- C11 (22 пФ C0G/NP0, 10–33 пФ) — выборка напряжения с линии ANT (`J_ANT_1`) на узел `SWR_RF`; вместе с вторичкой T3 образует мост: падающая волна гасится → при согласовании 50 Ом `SWR_sense`≈0.
- D4 (выпрямитель, BAT54W): A←`SWR_RF`, K→`SWR_sense`; D5 (фиксатор): A→GND, K→`SWR_RF`. C10 (100 нФ)+R15 (10 кОм) — фильтр/нагрузка. `SWR_sense → J_SWR_1:1`.
- Настройка: с эквивалентом 50 Ом на `J_ANT_1` подобрать C11 (10–33 пФ) / фазировку вторички до минимума `SWR_sense`.

## 7. J_ANT_1 (плата)
- BNC BJ2 — на задней крышке (панель), коаксиалом на плату. На плате — SMA edge-mount (s-p215, как J_RF_TX_1/J_RF_RX_1) как точка подключения коаксиала: `Connector_Coaxial:SMA_Amphenol_132289_EdgeMount`.

## 8. Драйвер-каскад
- Не ставим (расчёт: запас ×1.67 / +2.2 дБ). R_fb1/R_fb2 (150 Ом) — резервное место под ОС, помечены DNP.
