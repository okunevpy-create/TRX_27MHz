# BOM — списки компонентов

## Правила
- BOM ведётся по этапам: `stageN_*.md`.
- Сводный список — `bom_master.csv` (Designator, Value, Footprint, Qty, Supplier, Price, Alternative).
- **Перед разводкой этапа** проверить, что все позиции заказаны. Худший срок доставки — 3–4 дня; это время использовать для травления и сверловки.
- Для каждой критичной позиции — альтернатива (если основная недоступна).

## Файлы
- `bom_master.csv` — сводный
- `stage1_control.md` — этап 1
- `stage2_power_amp.md` — этап 2
- `stage3_rx_tx.md` — этап 3
