# BOM — Этап 3: тракт RX/TX (03_rx_tx)

> **ПРЕДВАРИТЕЛЬНЫЙ (черновик).** Состав/номиналы/корпуса фиксируются в подэтапах 3.1–3.5. Ниже — каркас BOM по архитектуре `block-diagram.md` и контрактам `control_rxtx.md` / `rxtx_pa.md`.
>
> Правила: пассивные R/C в сигнальных цепях — 0603 (handsoldering); ВЧ-конденсаторы BPF/согласования — **C0G/NPO 100 В**; электролиты — SMD; разъёмы — с индексом на конце (`_1`).

## Назначение документа
BOM служит **ТЗ для отдельной KiCad-сессии (MCP)** этапа 3. Здесь — каркас состава и открытые вопросы до проработки 3.1–3.5.

## Частотный план (основа)
- Приёмный тракт: 27 МГц → BPF → 1-й смеситель (VFO 37,7 МГц) → **ПЧ 10,7 МГц** → кварцевый фильтр → детектор AM/SSB → УНЧ.
- Передача: MIC_LINE (line-level ~100 мВ) → формирователь SSB (фазовый, I/Q) → балансный модулятор → BPF 27 МГц → TX_RF.
- VFO = 37,7 МГц (верхняя гетеродинная, ~1 В pp), BFO = 10,7 МГц (~1 В pp), I/Q — НЧ-квадратура ~0,5 В pp (с `01_control`).

> 1. **TX-раскачка 0,5 Вт:** SA612 на выходе даёт ~−10 дБм, а контракт требует ~0,5 Вт. **РЕШЕНО: драйвер = 2SC2078** (NPN, TO-220, ~0.5–1 Вт, fT ~175 МГц) — каскад на `03_rx_tx` в 3.4.

## Сводный дефицит (TO-ORDER)
**Весь актив этапа 3 — TO-ORDER (этап ещё не начат):**
- **NE612AD (SOP-8) ×3** (≡ SA612A/NE602) — **ЗАКАЗАН**; смеситель RX + модулятор TX + продукт-детектор SSB.
- **Кварцы 10,7 МГц HC-49 ×4** (+2 запас на подбор) + связующие C0G/NPO конденсаторы.
- **LM386 ×1**, **LM7809 ×1**, локальный LDO смесителей ×1.
- **Катушки BPF 27 МГц** (~4) + C0G/NPO конденсаторы BPF (~6).
- **Драйвер TX = 2SC2078** (РЕШЕНО, **ЗАКАЗАН**) ×1 + обвязка (смещение/согласование).

**STOCK / переиспользуется с этапов 1–2:** 1N4148WS, BAT54, пассив 0603, C0G, XH2.54 (набор), SMA, клеммник WJ127R-5.0-02P (1 из заказанных ×3).
