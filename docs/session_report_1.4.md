## Выбранные футпринты

- Резисторы R23–R28: **0603** (Metric 1608), handsoldering-вариант.
- C39 / C40: **0603**; C41 (10 мкФ) — **0805** (в 0603 нет 10 мкФ).
- U7 LM358: `Package_SO:SOIC-8_3.9x4.9mm_P1.27mm_HandSolder` (из F3, не менялся).

## Замечания / отклонения от промта

- В промте `MIC_LINE` названа «иерархической меткой»; по факту использована
  **глобальная** метка — корректно для межблочного сигнала (AGENTS.md §4),
  электрически эквивалентно для мастер-листа `00_master`.
- Лист увеличен с A3 до **A2** (пользователем) для размещения обвязки MIC без
  наложений.
- `J_OLED` переразведён пользователем под фактический порядок модуля ST7789
  (1=GND, 2=`+3V3_DISP`, 3=`OLED_SCK`, 4=`OLED_MOSI`, 5=`LCD_RST`, 6=`OLED_DC`,
  7=`OLED_CS`, 8=`LCD_BLK`) — см. `docs/bom/stage1_control.md` §1.4.
