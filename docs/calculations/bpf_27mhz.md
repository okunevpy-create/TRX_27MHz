# BPF 27 МГц — двухконтурный полосовой фильтр (подэтап 3.1)

## Требование
Пропустить полосу СиБи 26.965–27.405 МГц с минимальными потерями и согласованием 50 Ом,
подавить:
- **зеркальный канал RX = 47 МГц** (VFO 37 МГц верхняя гетеродинная, ПЧ 10 МГц → 37+10);
- **2-ю гармонику TX = 54 МГц** (основную фильтрацию гармоник дополнительно делает ФНЧ на `02_power_amp`).

Фильтров два, одинаковых: **RX-входной** (`J1` → смеситель 3.2) и **TX-выходной**
(модулятор 3.4 → `J2`).

## Топология
**Ёмкостно-связанный двухконтурный полосовой фильтр (2 полюса, Баттерворт)** — 2 катушки + 5
конденсаторов на фильтр. Индуктивности фиксированные SMD 0.47 мкГн (заказаны).

```
IN o-- Cin --+-- Cc --+-- Cout --o OUT
             |        |
             L        L
             |        |
             Ct       Ct
             |        |
            GND      GND
```

- `L` — резонансная катушка (0.47 мкГн).
- `Ct` — подстроечный конденсатор контура (параллельно L).
- `Cin`, `Cout` — согласующие конденсаторы входа/выхода (последовательно, 50 Ом).
- `Cc` — конденсатор связи между контурами (задаёт полосу).

## Параметры проектирования
- `f0 = 27.2 МГц` (центр полосы 26.965–27.405 МГц ≈ 27.185 МГц).
- `BW = 1.5 МГц` (−3 дБ, запас над полосой 440 кГц).
- `FBW = BW/f0 = 0.0551`.
- `L = 0.47 мкГн` (MLF2012DR47KT000, 0805).
- Прототип Баттерворта 2-го порядка: `g0=1, g1=1.4142, g2=1.4142, g3=1`.

## Расчёт (J-инверторы, синтез с учётом крутизны реактивности)
Крутизна реактивности параллельного LC-контура: `b = ω0·C_res = 1/(ω0·L)`.

| Величина | Формула | Значение |
|----------|---------|----------|
| `ω0` | `2π·f0` | `1.7090e8` рад/с |
| `C_res` | `1/(ω0²·L)` | **72.85 пФ** |
| `b` | `1/(ω0·L)` | `0.01245` См |
| `J01 = J23` | `√(G·b·FBW/(g0·g1))` | `3.116e-3` См |
| `J12` | `FBW·√(b·b/(g1·g2))` | `4.855e-4` См |
| `Cin = Cout` | `J01/ω0` | **18.2 пФ** |
| `Cc` | `J12/ω0` | **2.84 пФ** |
| `Ct` | `C_res − Cin − Cc` | **51.8 пФ** |

> ⚠️ Синтез J-инвертора на последовательном конденсаторе требует **вычесть** соседние
> конденсаторы связи из подстроечной ёмкости (`Ct = C_res − Cin − Cc`). Без этой поправки
> контуры резонируют выше f0 (проверено SPICE), и полоса «расползается».

## Номиналы (ближайшие E24, C0G/NPO 100 В 0805)
| Элемент (на фильтр) | Теория | E24 | Кол-во на фильтр |
|---------------------|--------|-----|------------------|
| `L` | 0.47 мкГн | **0.47 мкГн** (фикс.) | 2 |
| `Ct` | 51.8 пФ | **51 пФ** | 2 |
| `Cin`/`Cout` | 18.2 пФ | **18 пФ** | 2 |
| `Cc` | 2.84 пФ | **2.7 пФ** | 1 |

**Итого на фильтр: 2×L + 5×C0G.** На два фильтра: **4×L + 10×C0G**
(4×51 пФ + 4×18 пФ + 2×2.7 пФ).

## Проверка SPICE (ngspice, AC 15–60 МГц, идеальные L/C, 50 Ом)
Итоговая конфигурация `51 пФ / 18 пФ / 2.7 пФ`:

| Частота | `|S21|` (gain dB) | Примечание |
|---------|-----------------|------------|
| 26.965 МГц | −7.32 | нижний край полосы, в полосе |
| 27.405 МГц | −6.03 | верхний край полосы, в полосе |
| 27.51 МГц (пик) | −6.02 | **согласование 50 Ом** (0.5 = −6 дБ) |
| 30 МГц | −25 | вне полосы |
| 47 МГц | **−45.0** | **зеркальный канал RX** |
| 54 МГц | **−45.9** | **2-я гармоника TX** |

- Центр ≈ **27.5 МГц** (чуть выше номинала — 51 пФ), вся полоса СиБи укладывается с потерями ≤ 1.3 дБ.
- Полоса −3 дБ ≈ **1.4 МГц**.
- Подавление зеркального канала и 2-й гармоники **≥ 45 дБ** — достаточно для входного фильтра
  (селективность по соседнему каналу обеспечивает кварцевый фильтр ПЧ 10 МГц в 3.2).

## Настройка (бенч)
1. Собрать фильтр между 50-омным генератором и 50-омной нагрузкой (VNA/КСВ-метр).
2. Проверить КСВ ≤ 1.5 на 27 МГц и потери < 1 дБ в полосе.
3. При смещении центра — подобрать `Ct` (47/51/56 пФ) и `Cc` (2.2/2.7/3.3 пФ) по КСВ/спектру.
