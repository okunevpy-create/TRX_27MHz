# Расстройка SSB (RIT)

## Требование
Удобная расстройка приёма для SSB: ±1 кГц, шаг 10 Гц / 100 Гц, индикация на OLED, сброс.

## Реализация
- Программная поправка частоты Si5351 (CLK1 — VFO) при приёме.
- Энкодер: шаг 10 Гц (по умолчанию в SSB), 100 Гц — при нажатой кнопке.
- Кнопка RIT: включение/сброс (двойное нажатие — быстрый сброс).
- Хранение в EEPROM: значение RIT привязано к каналу (опционально — глобально).
- Автосброс при смене канала — настраиваемо.
- Плавность: обновление Si5351 раз в 50–100 мс при вращении, без «щелчков».

## Статус
Черновик. Уточняется в подэтапе 1.4 (UI) и при разработке прошивки.
