# ФНЧ 27 МГц (5-й порядок, Чебышёв 0.1 дБ)

## Требование
Пропустить 27 МГц (26.965–27.405 МГц, канал СиБи) с минимальными потерями, подавить гармоники (54, 81 МГц). Выход — на 50 Ом (антенна). Подэтап 2.2.

## Выбор топологии и частоты среза
- **Топология:** лестничная C–L–C–L–C (5 элементов, нечётный порядок, начинается и заканчивается шунтирующей ёмкостью). Удобна для 50 Ом и параллельного соединения двух ёмкостей в начале/конце.
- **Частота среза `fc` = 30 МГц** — запас над 27.405 МГц при сохранении подавления на 54 МГц (1.8·fc).
- **Характеристика:** Чебышёв, пульсации 0.1 дБ (острая режекция при малом искажении в полосе).

## Нормированные коэффициенты (Чебышёв 0.1 дБ, 5-й порядок)
| g | значение |
|---|----------|
| g1 | 1.1468 |
| g2 | 1.3712 |
| g3 | 1.9750 |
| g4 | 1.3712 |
| g5 | 1.1468 |
| g6 (нагрузка) | 1.0 |

## Расчёт номиналов (`Z0 = 50 Ом`, `fc = 30 МГц`)
Формулы:
- Ёмкость (шунт): `C = g / (2π · fc · Z0)`
- Индуктивность (последовательно): `L = g · Z0 / (2π · fc)`

| Элемент | Формула | Расчёт | Номинал (ближайший) |
|---------|---------|--------|---------------------|
| C1 (вх) | g1 / (2π·fc·Z0) | 1.1468 / (2π·30e6·50) = 121.7 пФ | **120 пФ** |
| L1 | g2·Z0 / (2π·fc) | 1.3712·50 / (2π·30e6) = 363.7 нГн | **360 нГн** |
| C2 (сред.) | g3 / (2π·fc·Z0) | 1.9750 / (2π·30e6·50) = 209.6 пФ | **220 пФ** |
| L2 | g4·Z0 / (2π·fc) | 1.3712·50 / (2π·30e6) = 363.7 нГн | **360 нГн** |
| C3 (вых) | g5 / (2π·fc·Z0) | 1.1468 / (2π·30e6·50) = 121.7 пФ | **120 пФ** |

**Итог: C–L–C–L–C = 120 пФ – 360 нГн – 220 пФ – 360 нГн – 120 пФ.**

## Ожидаемое подавление гармоник
На 2-й гармонике (54 МГц, ~1.8·fc) 5-порядковый Чебышёв даёт **≥ 30 дБ** подавления. На 3-й (81 МГц, ~2.7·fc) — ещё больше.

## Выбор компонентов (ВЧ-требования)
- **Конденсаторы:** **C0G/NPO, номинал 100 В**, корпус 0805/1206. Пиковое ВЧ на 50 Ом:
  - 12 Вт PEP: `Vpk = √(2·P·R) = √(2·12·50) = 34.6 В`
  - 4 Вт (AM): `Vpk = √(2·4·50) = 20 В`
  → 50 В маловато с запасом; **100 В** надёжно. **Не использовать X7R** (потери + ёмкостной дрейф на ВЧ).
- **Индуктивности:** тор **T50-6** (iron powder, тип 6, µ≈8), проволока эмалированная Ø0.5–0.7 мм, **~10 витков**. `N = √(L / AL)`; при AL(T50-6) ≈ 3.7 нГн/вит² → `N = √(360/3.7) ≈ 9.9 ≈ 10`. AL и число витков подтвердить по даташиту (Amidon/Fair-Rite), финально подобрать на макете по КСВ/спектру.

## Настройка (бенч)
1. Собрать ФНЧ между 50-омным генератором и 50-омной нагрузкой (или КСВ-метром).
2. Проверить проход на 27 МГц (потери < 0.5 дБ) и режекцию на 54/81 МГц.
3. При необходимости скорректировать витки L (±1) и номиналы C (180/200/220 пФ).
