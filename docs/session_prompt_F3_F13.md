## 1. Правила (КРИТИЧНО, не нарушать)

1. Файлы `.kicad_sch` / `.kicad_pro` / `.kicad_pcb` править **ТОЛЬКО через KiCad MCP-инструменты**. `write_file`/`edit_file`/`str_replace` на них **запрещены**.
2. Не редактировать один файл параллельно. Одна MCP-операция → перечитать → следующая. Не запускать параллельные KiCad-вызовы.
3. **Не запускать `sch_annotate`** — он перенумерует уже зафиксированные refdes.
4. **Никаких наложений** символов/полей/текста/проводов (§6 AGENTS.md). Перед вставкой смотри `sch_get_bounding_boxes`/`sch_find_free_placement`, после — `sch_visual_qa` (игнорируй ложное ~6.5 мм² «power-на-пине»).
5. Корпуса пассивов: **0603** (Metric 1608) + **HandSolder**-вариант футпринта. Исключения (осознанные): ферриты и электролиты — SMD; 10 мкФ в 0603 нет → **0805** `C_0805_2012Metric_Pad1.15x1.40mm_HandSolder`.
6. Пины 2-выводных пассивов (`Device:C`/`C_Polarized`/`FerriteBead`) при rot=0: **pin1 сверху = y−3.81 мм**, pin2 снизу = y+3.81 мм (НЕ ±2.54).
7. Питание (+5V/+3V3/+3V3_SI/+3V3_DISP) и GND соединять **глобальными метками** (MCP не добавляет power-символы для `trx_custom`). Это электрически эквивалентно. Для «горячих» цепей, которые ERC помечает `power_pin_not_driven`, ставь **`PWR_FLAG`** (символ `power:PWR_FLAG`).
8. Не трогай `sym-lib-table`/`fp-lib-table`. Символ **`trx_custom:RT9193-33`** резолвится, цоколёвка: **1=IN, 2=GND, 3=EN, 4=BP, 5=OUT**.
9. Имена межблочных сигналов НЕ менять: `VFO`, `BFO`, `I`, `Q`, `PTT`, `MIC_LINE`, `MUTE`, `RX_audio`, `+12V_PA`, `+12V_RXTX`, `PWR_LIMIT_EN`, `PWR_LIMIT_SW`, `I_sense`, `SWR_sense`.

## 3. Задачи сессии (F3–F13, по порядку)

После каждой вставки — перечитать элемент через MCP и проверить наложения.

### F3 — U7: LM358DR (SOIC-8)
- Символ: `Amplifier_Operational:LM358` (unit A; unit B — не используется).
- Footprint: `Package_SO:SOIC-8_3.9x4.9mm_P1.27mm_HandSolder`.
- Unit B: оба входа на GND, выход — NC (no-connect). Питание unit A/B общее (+3V3 / GND).
- Полную обвязку MIC-предусилителя (R_bias/R_in/R_fb/R_g/C_cpl) делать **НЕ здесь** — это 1.4.

### F4 — U6: 74HC74D (проверка цоколёвки)
- Символ `74xx:74HC74`, footprint `Package_SO:SOIC-14_3.9x8.7mm_P1.27mm` — оставить.
- Сверить цоколёвку со стандартом: 1=1CLR, 2=1D, 3=1CLK, 4=1PRE, 5=1Q, 6=1/Q, 7=GND, 8=2/Q, 9=2Q, 10=2PRE, 11=2CLK, 12=2D, 13=2CLR, 14=VCC. Отклонение — зафиксировать в отчёте.

### F5 — разъёмы → XH2.54 (угловые)
| Ref | Пины | Footprint |
|---|---|---|
| J_OLED | 8 | `Connector_JST:JST_XH_B8B-XH-A_1x08_P2.54mm_Vertical` (или `..._Horizontal` по монтажу) |
| J_ENC | 5 | `JST_XH_B5B-XH-A_1x05_P2.54mm_*` |
| J_BTN | 7 | `JST_XH_B7B-XH-A_1x07_P2.54mm_*` |
| J_PA_CTRL | **6** | `JST_XH_B6B-XH-A_1x06_P2.54mm_*` |
| J_RXTX_SIG | **10 (ОДИН, не 2×5)** | `JST_XH_B10B-XH-A_1x10_P2.54mm_*` |

Нет `Horizontal`-варианта XH — брать `Vertical` и зафиксировать.

### F5b — J_SWD / J_UART: НЕ МЕНЯТЬ (PinHeader 2.54, осознанное решение).

### F6 — J_PA_PWR / J_RXTX_PWR → клеммник 2-pin 5.0 мм (угловой)
- Footprint: `TerminalBlock_*:...1x02_P5.00mm_Horizontal` — подобрать ближайший (например `TerminalBlock_Phoenix:TerminalBlock_Phoenix_MKDS-1.5-2_1x02_P5.00mm_Horizontal`), зафиксировать выбор.
- Сигналы: `+12V_PA`/GND и `+12V_RXTX`/GND.

### F7 — U8: 74AC541SC (SOIC-20) + буферы VFO/BFO/IQ
- Символ `74xx:74AC541`; footprint `Package_SO:SOIC-20W_7.5x12.8mm_P1.27mm` (HandSolder при наличии).
- R_buf ×4 = **R19–R22** (22–47 Ом, 0603); C_buf ×1 = **C38** (100 нФ, 0603) у Vcc.
- Разводка:

| Банк | Буфер | Вход | Выход | OE |
|---|---|---|---|---|
| 1 | A1 | `VFO_RAW` (от U5 CLK0) | `VFO_OUT` через R_buf | 1OE → GND |
| 1 | A2 | `BFO_RAW` (от U5 CLK1) | `BFO_OUT` через R_buf | 1OE → GND |
| 1 | A3, A4 | **GND** | NC | 1OE → GND |
| 2 | A5 | `I` (от U6 Q1) | `I_OUT` через R_buf | 2OE → `IQ_EN` |
| 2 | A6 | `Q` (от U6 /Q2) | `Q_OUT` через R_buf | 2OE → `IQ_EN` |
| 2 | A7, A8 | **GND** | NC | 2OE → `IQ_EN` |

- `IQ_EN` — GPIO MCU (активный низкий), локальный, в межплатный разъём не выходит.
- Неиспользуемые входы (A3/A4/A7/A8) — **обязательно на GND** (AC-family не терпит висящих входов).

### F11 — U9: RT9193-33 (LDO дисплея) + развязка
- Символ `trx_custom:RT9193-33`, footprint `Package_TO_SOT_SMD:SOT-23-5` (как U2/U3).
- Вход от **+5V**, выход **+3V3_DISP** (только для J_OLED). EN → IN (всегда вкл), GND → GND.
- Развязка: **C26 = 1 мкФ (вход, 0603)**, **C27 = 10 мкФ (выход, 0805)**, **C28 = 10 нФ (BP, 0603)** — ровно как блок U2 (C5/C6/C23).

### F12 — J_OLED (8-pin) + именованные цепи
`J_OLED` (уже добавлен в F5) — раскладка:
| Пин | Сигнал | Цепь |
|---|---|---|
| 1 | VCC | `+3V3_DISP` (от U9) |
| 2 | GND | GND |
| 3 | SCK | `SPI_SCK` |
| 4 | MOSI | `SPI_MOSI` |
| 5 | CS | `SPI_CS` |
| 6 | DC/RS | `SPI_DC` |
| 7 | RST | `LCD_RST` |
| 8 | BLK | `LCD_BLK` |

Отдельный символ модуля (U10) не нужен — модуль на корпусе, на плате только разъём `J_OLED`.

### F13 — RC-фильтры UI (ОБЯЗАТЕЛЬНО)
| Назначение | Refdes | Значение | Кол-во |
|---|---|---|---|
| Pull-up J_BTN ×6 | R6–R11 | 10 кОм | 6 |
| Фильтр J_BTN ×6 | C29–C34 | 100 нФ | 6 |
| Pull-up J_ENC ×3 (CLK/DT/SW) | R12–R14 | 10 кОм | 3 |
| Фильтр J_ENC ×3 | C35–C37 | 100 нФ | 3 |
| Последоват. SPI OLED ×4 | R15–R18 | 22 Ом | 4 |

Схема на линию кнопки/энкодера:
```
+3V3 ── R_pu 10к ──┬── линия разъёма (кнопка замыкает на GND)
                   ├── C 100нФ ── GND
                   └── пин MCU
```
SPI-линии дисплея: R 22 Ом последовательно в SCK, MOSI, CS, DC. RST и BLK — без резистора.
