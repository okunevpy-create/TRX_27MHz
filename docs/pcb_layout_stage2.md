## 3. Зональная схема (рекомендация)

```
        ТЫЛ (Y≈0): J_ANT_1 (SMA)                     J_PA_PWR_1 (+12V_PA/GND)
      ┌───────────────────────────────────────────────────────────────┐
      │                                                               │
      │  [1. ВЧ/СИЛОВОЙ ТРАКТ]                                        │
      │   T1 → R1/R2 → Q1/Q2 (2× TO-220 на радиаторе HS 104-30)      │
      │   → T2 → L1(RFC) → ФНЧ L2/L3+C6/C7/C8 → K1 (реле)            │
      │                                                               │
      │  [2. ДАТЧИКИ + УПРАВЛЕНИЕ + СМЕЩЕНИЕ]                          │
      │   R16(шунт) + U1(LM358) + Q3/Q4/Q5(2N7002) + RV1 + D2/D3     │
      │   + J_PA_CTRL_1/J_I_SENSE_1/J_SWR_1                           │
      │                                                               │
      │  [3. LED + разъёмы панели]  D6/D7 + J_SW_1 + J_LIM_LED_1      │
      └───────────────────────────────────────────────────────────────┘
        ПЕРЕД: J_RF_TX_1  J_RF_RX_1  J_PA_CTRL_1  J_I_SENSE_1  J_SWR_1
```

- **Силовой ВЧ-тракт** (Q1/Q2, T1/T2, L1, LPF, K1) — компактно, по одной линии
  сигнала, вдали от датчиков и разъёмов управления.
- **Радиатор HS 104-30** — вдоль одной из длинных кромок, 2× TO-220 на общий
  радиатор (изоляторы + втулки M3 + термопаста).
- **Датчики/управление** (LM358, 2N7002, шунт, RV1) — отдельно от ВЧ, у разъёмов
  управления; аналоговые `I_sense`/`SWR_sense` — короткими дорожками к своим разъёмам.
- **Шунт R16 (2512)** — в минусовой шине `PA_RET → R16 → GND`, максимально близко
  к истокам Q1/Q2 и ко входу LM358 (IN1+ = `PA_RET`).

## 4. Net-классы цепей (Board Setup → Net Classes)

Настраивается **после** `Tools → Update PCB from Schematic` (чтобы net-ы существовали).
Net-класс задаёт **дефолтную ширину** для Freerouting (в отличие от DRC-правил,
которые ловят нарушения постфактум).

### 4.1 Классы для создания

| Net class | Ширина (мм) | Зазор (мм) | Назначение |
|-----------|-------------|------------|------------|
| `PWR_PA` | **1.5** | 0.4 | силовая магистраль УМ (3 А) |
| `RF_PA` | **1.0** | 0.4 | ВЧ-тракт 50 Ом + стоки (низкие потери) |
| *Default* | 0.6 | 0.4 | всё остальное (логика/датчики) |

### 4.2 Назначение цепей (Net Class Assignment, точные имена)

| Имя цепи | Net class |
|----------|-----------|
| `+12V_PA` | `PWR_PA` |
| `PA_RET` | `PWR_PA` |
| `RFC_IN` | `PWR_PA` |
| `ANT` | `RF_PA` |
| `LPF_IN` | `RF_PA` |
| `LPF_MID1` | `RF_PA` |
| `LPF_OUT` | `RF_PA` |
| `TX_RF` | `RF_PA` |
| `RX_RF` | `RF_PA` |
| `DRAIN1` | `RF_PA` |
| `DRAIN2` | `RF_PA` |
| всё остальное | *Default* |

> ⚠️ **Точные имена, НЕ wildcard** (`+12V*` и т.п.): иначе под шаблон попадут
> низкотоковые ветки `GATE1/GATE2`, `VGG*`, `G1_RF/G2_RF` — они должны остаться
> на Default 0.2.

### 4.3 Земля — отдельно (не net-класс)

- В схеме одна цепь `GND` (69 пинов). Отдельных `GND_DIG/GND_ANA/GND_PWR` **нет**.
- `GND` — сплошная заливка **с обеих сторон**, зазор полигона **0.5 мм**, **без
  thermal relief** (прямое соединение падов с полигоном).
- Разделение «силовое/сигнальное» — геометрией полигона (звезда в одной точке у
  bulk `C4` / входа `J_PA_PWR_1`), не отдельными net-ами.

Технология — **заклёпочные пистоны** (не проволочные перемычки).

| Параметр | Значение |
|----------|----------|
| Сверло | **0.9 мм** |

## 7. Разводка: F.Cu / B.Cu

**Ограничивает не тип цепи, а (1) минимум смен слоёв и (2) целостность GND-заливки.**

| Слой | Что ведём |
|------|-----------|
| **F.Cu** (основной, ~90 %) | весь ВЧ-тракт (`TX_RF`→T1→Q1/Q2→T2→LPF→K1→`ANT`), силовая магистраль `+12V_PA`/`PA_RET`/`RFC_IN`, датчики |
| **B.Cu** | короткие «перемычки через препятствие» (не влезло на F.Cu), при необходимости магистрали `+12V_PA` |

Жёсткие ограничения:
- **Каждый переход F.Cu↔B.Cu = заклёпочный пистон = лишняя ручная операция** → переходов минимум.
- **ВЧ-тракт — только F.Cu**, одной короткой линией, без перемычек по B.Cu; под ВЧ-дорожками — сплошной GND (B.Cu полигон).
- **Аналог (`I_sense`, `SWR_sense`, `PA_RET` к U1) — только F.Cu**, коротко, в стороне от ВЧ.
- **GND-заливка на B.Cu — максимально цельная** (обратный путь тока); длинные параллельные сигнальные дорожки по B.Cu режут землю — избегать.
- Силовой контур `C4/C3/C1/C2 → L1 → T2` — компактно, минимальная петля.
