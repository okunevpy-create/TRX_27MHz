## 2. Добавлено решением по корпусу — ТРЕБУЕТ ДОРАБОТКИ

### 2.1. Светодиодная индикация PWR / TX / LIM — ⚠️ НЕ ЗАЛОЖЕНА

**Обнаружено:** в проекте светодиодной индикации на передней панели **нет**.
Единственный упомянутый светодиод — на `02_power_amp`, в самой схеме
ограничителя (`docs/contracts/control_pa.md`, раздел «Ограничитель
мощности AM»: «Индикация: светодиод на `02_power_amp` (горит — LIMIT)»).
Это индикатор **на плате УМ**, а не на корпусе.

**Добавлено при разводке панели:** колонка из 3 светодиодов справа.

| LED | Смысл | Откуда сигнал |
|-----|-------|---------------|
| PWR | питание включено | +5V / +3V3 (постоянно) |
| TX | передача | PTT |
| LIM | ограничитель активен | соответствует `PWR_LIMIT_SW` с узла УМ |

**Что требуется для реализации:**

1. **Схема `01_control`**: драйверы светодиодов (резистор + транзистор/пин MCU).
   Нужно 3 выхода GPIO (или 2 — если PWR повесить на питание напрямую).
   Сейчас в `J_BTN` (7 пинов) все расписаны — свободных нет.
   **Решение:** добавить отдельный разъём `J_LED` (3–4 пина) или расширить `J_BTN` до 10.
2. **Прошивка**: управление TX и LIM.
   `PWR_LIMIT_SW` уже читается (см. контракт), поэтому LIM — просто проброс.
3. **BOM**: 3 × светодиод 3 мм + 3 × резистор (0603).
4. **Контракт `control_pa.md`**: уточнить, что LIM на панели = `PWR_LIMIT_SW`.

**Светодиод на `02_power_amp`** (в схеме ограничителя) остаётся — он
индицирует состояние на самой плате УМ. Дублирование сознательное:
на панели видно водителю, на плате — при наладке.

### 2.2. Разъёмы гарнитуры — уточнение

Контракт говорит «на корпусе (передняя панель)», но **между пунктами
контракта есть противоречие**: фраза «MIC, PTT → пады на `01_control` →
корпусной разъём 2.5 мм» не указывает сторону панели.

**Зафиксировано решением по корпусу:** оба разъёма — на **передней** панели,
в зазоре между экраном и энкодером, вертикально (3.5 сверху, 2.5 снизу).

**Риск:** провод гарнитуры будет свисать спереди через экран и энкодер.
Если окажется неудобно — перенос на заднюю панель это правка одного
параметра (`HS_CENTER_X/Y`), геометрия пересоберётся.
