# KiCad-проекты

Каждый этап — отдельная папка. Локальные библиотеки — в `libs/`.

```
KiCad/
├── libs/
│   ├── symbols/
│   ├── footprints/
│   └── 3dmodels/
├── 00_master/       — этап 0: мастер-лист (только schematic, без PCB)
├── 01_control/      — этап 1: плата управления
├── 02_power_amp/    — этап 2: усилитель мощности
└── 03_rx_tx/        — этап 3: тракт RX/TX
```

## Этапы
| Этап | Папка | Подэтапы |
|------|-------|----------|
| 0 | `00_master` | — |
| 1 | `01_control` | 1.1–1.5 |
| 2 | `02_power_amp` | 2.1–2.4 |
| 3 | `03_rx_tx` | 3.1–3.5 |
| 4 | `Mechanical/` | 4.1–4.5 (FreeCAD, не здесь) |

## Как открыть проект на свежем клоне
1. Открыть папку проекта, например `01_control/`.
2. KiCad подхватит `fp-lib-table` и `sym-lib-table` автоматически.
3. Локальные библиотеки — через `${KIPRJMOD}/../libs/...`.
4. **`.kicad_pro` появится при первом сохранении** — добавить в git после открытия.

## Правила
- **Правка `.kicad_sch` / `.kicad_pcb` — только через MCP-инструменты KiCad** (см. `AGENTS.md`).
- **Перед разводкой** — проверить `docs/contracts/` и `docs/bom/`.
- **`00_master` — schematic-only**, PCB не создаётся.
- **⚠️ Плату этапа 1 не травить и не монтировать** до завершения совместных подэтапов 1.5 + 2.3.
- Не коммитить `*-backups/`, `*.kicad_prl`, `fp-info-cache`, `gerbers/`, `*.gbr`, `*.drl`.
- Коммитить: `.kicad_pro`, `.kicad_sch`, `.kicad_pcb`, `fp-lib-table`, `sym-lib-table`.

## 3D-модели
- 3D-модели **компонентов** — в `libs/3dmodels/`.
- 3D-модели **корпуса станции** — в `Mechanical/` (не здесь).

## Глобальные параметры
- 2 слоя, медь 35 мкм.
- VIA: diameter 2.5 мм, drill 0.9 мм, hole-to-hole 2.5 мм.
- Дорожка 0.25 мм, зазор 0.2 мм.
- Зенковка 1.2 мм.
