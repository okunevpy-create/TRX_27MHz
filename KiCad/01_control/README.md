# 01_control — плата управления (этап 1)

## Подэтапы
- **1.1** — Входной узел защиты (без F1, питание от LTC3780 13,8 В) + DC-DC 12→5 В (LM2596S-5.0) + LDO 3,3 В + `+3V3_SI`
- **1.2** — MCU: STM32F411 + кварц + SWD + UART + EEPROM (AT24C02C, I²C)
- **1.3** — Синтезатор: Si5351 + буферы VFO/BFO
- **1.4** — UI: OLED + энкодер + память каналов + RIT + squelch (программный); пады под проводной монтаж: MIC (с корпусного разъёма 2.5 мм), PTT (с корпусного разъёма 2.5 мм), GND; цепь питания электрета (резистор 2–10 кОм от +3.3 В), микрофонный предусилитель, выход `MIC_LINE`
- **1.5** — Интерфейсы и логика: PTT, входы I_sense/SWR_sense/PWR_LIMIT_SW/RX_audio, выход PWR_LIMIT_EN, разъёмы; вход `PTT` с гарнитуры (чтение MCU), выход `MUTE` на `03_rx_tx`

## Ключевые компоненты
- STM32F411CEU6 (LQFP-48), кварц 8 МГц, SWD, UART, USB DFU.
- EEPROM AT24C02C (SOIC-8/SOP-8, I²C 0x50) — хранение RIT/каналов (U10 + C45 100 нФ).
- Si5351A-B-GT (MSOP-10) + посадочное место под модуль.
- LM2596S-5.0 (TO-263) → LDO 3,3 В; отдельный LDO `+3V3_SI`.
- Входной узел защиты: TVS SMBJ18A + SS34 (второй рубеж); предохранитель 3 А снят с платы, защита входа перенесена на корпус (5 А + TVS load dump + SS54) перед предрегулятором LTC3780 13,8 В / 7 А.
- ≤ 9×9 см, 2 слоя, VIA — клёпки 0.9 мм.

## Разъёмы
- J_PA_CTRL — см. `docs/contracts/control_pa.md`
- J_RXTX_SIG — см. `docs/contracts/control_rxtx.md`
- Питание: вход `J_12V_IN_1`; раздача +12V на УМ/RX-TX — через внешние WAGO 221-415 (не через плату).
- OLED, энкодер, SWD, UART, USB.

## ⚠️ Порядок работ и запрет на изготовление
1. Зафиксировать `control_pa.md` и `control_rxtx.md`.
2. Схемотехника 1.1–1.4.
3. Схемотехника этапа 2, подэтапы 2.1–2.2.
4. **Совместно** 1.5 + 2.3.
5. **Только после этого** — травление и монтаж платы этапа 1.

До шага 5 разрешена только схемотехника и разводка в KiCad, без травления.
