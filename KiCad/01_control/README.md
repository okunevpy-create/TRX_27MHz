# 01_control — плата управления (этап 1)

## Подэтапы
- **1.1** — Входной узел защиты + DC-DC 12→5 В + LDO 3,3 В + `+3V3_SI`
- **1.2** — MCU: STM32F411 + кварц + SWD + UART
- **1.3** — Синтезатор: Si5351 + 74HC74 (квадратура) + буферы VFO/BFO/IQ
- **1.4** — UI: OLED + энкодер + память каналов + RIT + squelch (программный)
- **1.5** — Интерфейсы и логика: PTT, входы I_sense/SWR_sense/PWR_LIMIT_SW/RX_audio, выход PWR_LIMIT_EN, разъёмы

## Ключевые компоненты
- STM32F411CEU6 (LQFP-48), кварц 8 МГц, SWD, UART, USB DFU.
- Si5351A-B-GT (MSOP-10) + посадочное место под модуль.
- 74HC74 (SOIC-14).
- LM2596S-5.0 (TO-263) → LDO 3,3 В; отдельный LDO `+3V3_SI`.
- Входной узел защиты: P6KE18A, S34A, предохранитель.
- ≤ 9×9 см, 2 слоя, VIA — клёпки 0.9 мм.

## Разъёмы
- J_PA_CTRL, J_PA_PWR — см. `docs/contracts/control_pa.md`
- J_RXTX_SIG, J_RXTX_PWR — см. `docs/contracts/control_rxtx.md`
- OLED, энкодер, SWD, UART, USB.

## ⚠️ Порядок работ и запрет на изготовление
1. Зафиксировать `control_pa.md` и `control_rxtx.md`.
2. Схемотехника 1.1–1.4.
3. Схемотехника этапа 2, подэтапы 2.1–2.2.
4. **Совместно** 1.5 + 2.3.
5. **Только после этого** — травление и монтаж платы этапа 1.

До шага 5 разрешена только схемотехника и разводка в KiCad, без травления.

## Статус
Схемотехника (подэтапы 1.1–1.4).
