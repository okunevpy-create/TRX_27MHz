# 03_rx_tx — тракт RX/TX (этап 3)

## Подэтапы
- **3.1** — BPF 27 МГц
- **3.2** — Смеситель + ПЧ 10 МГц + кварцевый фильтр
- **3.3** — Детектор AM/SSB + УНЧ + защита входа RX (диоды + аттенюатор); разъём `J_SP_1` (XH2.54 2P) под проводной монтаж: SP+ и GND (к корпусному разъёму 3.5 мм); вход `MUTE` (управление mute-транзистором на входе LM386)
- **3.4** — Формирователь SSB (фильтровый метод: DSB @10 МГц → кварцевый фильтр) + драйвер TX 2SC2078; модулятор принимает `MIC_LINE` с `01_control`
- **3.5** — Питание: 12 В → LM7809 → локальные LDO

## Назначение
- Смеситель на SA612.
- ПЧ 10 МГц + кварцевый фильтр.
- Детектор AM/SSB, УНЧ на LM386.
- Формирователь SSB фильтровым методом (балансный модулятор NE612 DSB @10 МГц → лестничный кварцевый фильтр).
- BPF 27 МГц.
- Защита входа RX от просачивания при передаче.
