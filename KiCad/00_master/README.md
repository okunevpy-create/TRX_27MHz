# 00_master — мастер-лист (Этап 0)

Корневой лист иерархии. Содержит три иерархических листа:
- `01_control` (этап 1)
- `02_power_amp` (этап 2)
- `03_rx_tx` (этап 3)

Соединён проводниками на уровне блок-диаграммы. Здесь фиксируются **все межблочные сигналы** как иерархические пины.

## Назначение
- Зафиксировать интерфейсы до разводки блоков.
- Прогнать ERC по всей системе.
- Быть источником правды для `docs/contracts/`.

## Правила
- **PCB в этом проекте не создаётся.** Только schematic.
- Файлы блоков (`../01_control/01_control.kicad_sch` и т.д.) — **те же**, что в их проектах. Мастер ссылается на них, не копирует.
- При добавлении нового межблочного сигнала: сначала в мастер (пин на листе), затем в блок (иерархическая метка).
- ERC должен быть чистым.

## Статус
Иерархия создана (3 листа), пины импортированы. Идёт соединение проводниками.

## Межблочные сигналы в мастер-листе (Шаг 0.3)
Список пинов по листам (должен совпадать с `docs/contracts/`):

**01_control** (выходы/входы):
`PTT`, `I_sense`, `SWR_sense`, `PWR_LIMIT_EN`, `PWR_LIMIT_SW`, `VFO`, `BFO`, `I`, `Q`, `RX_audio`, `MIC_LINE`, `MUTE`, `+12V_PA`, `+12V_RXTX`, `GND`

**02_power_amp**:
`PTT`, `I_sense`, `SWR_sense`, `PWR_LIMIT_EN`, `PWR_LIMIT_SW`, `TX_RF`, `RX_RF`, `+12V_PA`, `GND`

**03_rx_tx**:
`VFO`, `BFO`, `I`, `Q`, `RX_audio`, `PTT`, `MIC_LINE`, `MUTE`, `TX_RF`, `RX_RF`, `+12V_RXTX`, `GND`

`GND` на Этапе 0 — один логический пин, физически не соединяется (см. `docs/inter-module-pinout.md`).
